# Subtitle-Translator-Converter 🎬📝 (نسخه فارسی)

خسته شدی از ترجمه‌های بی‌روح، ماشینی و کلمه به کلمه‌ی گوگل ترنسلیت؟ یا سایت‌های ترجمه زیرنویسی که هم کلی تبلیغ دارند و هم آخرش یک فایل خراب و بی‌معنی تحویلت می‌دهند؟ 🙄

این پروژه اینجاست تا کار را تمام کند! **Subtitle-Translator-Converter** به شما اجازه می‌دهد کاملاً **رایگان**، فیلم‌ها، سریال‌ها و ویدیوهای آموزشی محبوبتان را به **بیش از ۵۰ زبان مختلف دنیا** و با دقیق‌ترین و طبیعی‌ترین لحن ممکن ترجمه کنید. چطوری؟ با قدرت هوش مصنوعی **Gemini** که اصطلاحات و ریزه‌کاری‌های زبان را مثل یک مترجم انسان می‌فهمد! 😎

---

## ✨ چرا این برنامه یک سر و گردن از بقیه بالاتر است؟

- **🌍 پشتیبانی از بیش از ۵۰ زبان دنیا:** فرقی نمی‌کند زیرنویس شما انگلیسی، کره‌ای، فرانسوی، اسپانیایی یا هر زبان دیگری باشد؛ برنامه به راحتی آن را به فارسی یا بیش از ۵۰ زبان زنده دیگر ترجمه می‌کند.
- **🎭 انتخاب لحن ترجمه (قابلیت اختصاصی):** قبل از شروع می‌توانید لحن ترجمه را دقیقاً متناسب با ویدیوی خودتان انتخاب کنید:
  - 🍿 **سینمایی و درام:** برای فیلم‌ها و سریال‌های جدی.
  - 😂 **کمدی و عامیانه:** برای سیتکام‌ها و فیلم‌های طنز (ترجمه اصطلاحات و شوخی‌ها).
  - 🎓 **آموزشی و تخصصی:** برای کورس‌ها، یوتیوب و ویدیوهای علمی.
  - 👔 **رسمی و کتابی:** برای مستندها و ویدیوهای شرکتی.
- **🔑 بدون نیاز به تنظیمات سخت کدنویسی:** لازم نیست بروید فایل‌های سیستم را دستکاری کنید! برنامه را که باز کنید، خیلی راحت یک دکمه وجود دارد؛ کلید API رایگان جمنای خود را درون کادر وارد می‌کنید و تمام! 
- **💰 ۱۰۰٪ رایگان و بدون تبلیغات:** نیازی به خرید اشتراک یا دیدن بنرهای اعصاب‌خردکن نیست. مستقیم و بی‌واسطه با API خودتان کار می‌کند.
- **⏱️ حفظ کامل زمان‌بندی (Timing):** ساختار فایل زیرنویس شما دقیقاً حفظ می‌شود و زمان‌بندی‌ها حتی یک میلی‌ثانیه هم جابه‌جا نمی‌شوند.

---

## ⚠️ نکات بسیار مهم (قبل از شروع)

💡 **کیفیت بالا زمان می‌برد!** به دلیل اینکه هوش مصنوعی جمنای تک‌تک جملات را با دقت بالا پردازش می‌کند و لحن انتخابی شما را روی متن اعمال می‌کند، فرآیند ترجمه **ممکن است کمی طول بکشد**. این زمان بسته به **حجم زیرنویس، سرعت اینترنت و کشش سیستم شما** متغیر است. پس اگر دیدید پردازش طولانی شد، اصلاً نگران نباشید و صبور باشید؛ برنامه دارد کارش را دقیق انجام می‌دهد! ☕️✨

🛑 **راهنمای کاربران داخل ایران (رفع تحریم):** از آنجایی که شرکت گوگل و هوش مصنوعی جمنای آی‌پی‌های ایران را مسدود کرده‌اند، برای استفاده از برنامه **حتماً باید از یک وی‌پی‌ان (VPN) مناسب استفاده کنید**. توجه داشته باشید که فیلترشکن شما باید روی حالت **تان مود (TUN Mode)** فعال باشد (برای مثال قابلیت **TUN Mode در نرم‌افزار V2ray** کاملاً کفایت می‌کند و پاسخگو است).

## 📦 راهنمای گام‌به‌گام و آسانِ اجرای برنامه

برای اجرای برنامه روی سیستم خود، این مراحل ساده را به ترتیب انجام دهید:

### پیش‌نیاز
قبل از هر چیز، مطمئن شوید که نرم‌افزار **Node.js** روی کامپیوتر شما نصب است.

### ۱. دانلود و استخراج پروژه
سورس پروژه را از گیت‌هاب دانلود کرده و فایل Zip را روی سیستم خود از حالت فشرده (اکسترکت) خارج کنید.

### ۲. باز کردن خط فرمان (CMD) در پوشه پروژه
وارد پوشه اصلی پروژه (جایی که فایل‌ها قرار دارند) شوید. در نوار آدرس بالای پنجره ویندوز (جایی که مسیر پوشه را نوشته)، کلیک کنید، کلمه‌ی `cmd` را تایپ کرده و کلید **Enter** را بزنید تا خط فرمانِ سی‌ام‌دی مستقیماً در همین پوشه باز شود.

### ۳. نصب پکیج‌های مورد نیاز
(دستور زیر را در CMD وارد کنید تا پکیج‌ها نصب شوند؛ این کار ممکن است مدتی طول بکشد):

```text
npm install
```

### ۴. اجرای برنامه و استفاده!
دستور زیر را برای استارت زدن پروژه وارد کنید:

```text
npm run dev
```

پس از اجرای دستور، مرورگر خود را باز کرده و به آدرس زیر بروید:
```text
http://localhost:3000
```
**توجه:** برای استفاده از برنامه، پنجره ترمینال (CMD) حتماً باید باز بماند. حالا کلید API خود را وارد کنید، لحن دلخواهتان را بسنجید، زیرنویس را آپلود کنید و تمام! 🚀

# Subtitle-Translator-Converter 🎬📝 (English Version)

Tired of lifeless, literal, and robotic machine translations like Google Translate? Or subtitle translation websites filled with annoying ads that end up giving you a broken or corrupted file? 🙄

This project is here to change the game! **Subtitle-Translator-Converter** allows you to translate your favorite movies, series, and educational videos into **over 50 different languages** completely **for FREE**. It delivers highly accurate and natural translations powered by **Google Gemini AI**, which understands context, idioms, and nuances just like a human translator! 😎

---

## ✨ Why Choose This Tool?

- **🌍 50+ Languages Supported:** Whether your subtitle is in English, Korean, French, Spanish, or any other language, you can easily translate it into Persian or over 50 living languages worldwide.
- **🎭 Context-Aware Tone Selection (Exclusive Feature):** Choose the perfect tone that matches your video before starting the translation:
  - 🍿 **Cinematic & Drama:** For serious movies and TV shows.
  - 😂 **Comedy & Slang:** For sitcoms and comedies (expertly translates jokes and idioms).
  - 🎓 **Educational & Technical:** For online courses, YouTube tutorials, and scientific videos.
  - 👔 **Formal & Literary:** For documentaries and corporate presentations.
- **🔑 Zero Coding Configuration:** No need to modify environment files or system settings! Simply open the app, click the dedicated button, paste your free Gemini API key inside the input box, and you are ready to go!
- **💰 100% Free & Ad-Free:** No subscriptions, no limits, and no annoying pop-ups. It connects directly and privately to your own API key.
- **⏱️ Perfect Timestamp Preservation:** Your subtitle file structure remains untouched. Time codes and sequence numbers are preserved down to the millisecond—no audio-sync drifting!

---

## ⚠️ Important Notes (Before You Start)

💡 **High Quality Takes Time!** Because Gemini AI processes every sentence carefully to apply your selected tone, the translation **might take some time**. This duration depends on the **subtitle file size, your internet speed, and system capabilities**. If it seems to take a while, don't worry! The app is carefully doing its magic. Pour yourself a cup of coffee and enjoy the result! ☕️✨

🛑 **For Users Inside Iran (Bypassing Restrictions):** Since Google Gemini restricts Iranian IP addresses, **you must use a suitable VPN** to run the app. Please ensure your VPN is set to **TUN Mode** (for instance, enabling **TUN Mode in V2ray** works perfectly).

## 📦 Step-by-Step Installation & Quick Start

Follow these simple steps to run the application locally on your computer:

### Prerequisites
Make sure you have **Node.js** installed on your system.

### 1. Download and Extract the Project
Download the repository from GitHub and extract the Zip file anywhere on your computer.

### 2. Open Command Prompt (CMD) in the Project Folder
Navigate inside the main project directory (where the files are located). Click on the window's top address bar (where the folder path is written), type `cmd`, and press **Enter**. This opens the command prompt directly in that folder.

### 3. Install Required Packages
(Type the following command in CMD and press Enter to install dependencies; this might take a moment):

```text
npm install
```

### 4. Run the App!
Launch the local server using this command:

```text
npm run dev
```

Once executed, open your web browser and go to:
```text
http://localhost:3000
```
**Note:** The terminal window (CMD) must remain open while using the app. Now, enter your API key, choose your tone, upload your subtitle, and enjoy! 🚀
