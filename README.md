# Subtitle-Translator-Converter 🎬📝 (نسخه فارسی)
...
خسته شدی از ترجمه‌های بی‌روح، ماشینی و کلمه به کلمه‌ی گوگل ترنسلیت؟ یا سایت‌های ترجمه زیرنویسی که هم کلی تبلیغ دارند و هم آخرش یک فایل خراب و بی‌معنی تحویلت می‌دهند؟ 🙄

این پروژه اینجاست تا کار را تمام کند! **Subtitle-Translator-Converter** به شما اجازه می‌دهد کاملاً **رایگان**، فیلم‌ها، سریال‌ها و ویدیوهای آموزشی محبوبتان را به **بیش از ۵۰ زبان مختلف دنیا** و با دقیق‌ترین و طبیعی‌ترین لحن ممکن ترجمه کنید. چطوری؟ با قدرت هوش مصنوعی **Gemini** که اصطلاحات و ریزه‌کاری‌های زبان را مثل یک مترجم انسان می‌فهمد! 😎

## 🆕 قابلیت‌های جدید نسخه اخیر

- **🔑 پشتیبانی از چند کلید API به‌صورت هم‌زمان:** دیگر نگران لیمیت‌شدن یا خراب‌شدن کلید API نباشید! می‌توانید چند کلید Gemini را همزمان به برنامه بدهید و اگر یکی از کلیدها به لیمیت خورد یا با خطا مواجه شد، برنامه به‌صورت خودکار سراغ کلید بعدی می‌رود و روند ترجمه بدون وقفه ادامه پیدا می‌کند.
- **🎬 تولید خودکار زیرنویس از روی ویدیو (Speech-to-Subtitle):** یکی از بزرگ‌ترین قابلیت‌های این نسخه! کافیست یک ویدیوی بدون زیرنویس (به هر زبانی) را به برنامه بدهید؛ برنامه به‌صورت خودکار گفتار ویدیو را تشخیص داده و یک فایل زیرنویس برایش می‌سازد. از همان‌جا می‌توانید همین زیرنویس تازه‌ساخته‌شده را به هر زبان دیگری ترجمه کنید یا هر ویرایش دیگری روی آن انجام دهید.
- **▶️ پلیر پیش‌نمایش داخلی:** یک پلیر ویدیوی داخلی به برنامه اضافه شده که با آن می‌توانید همان لحظه ببینید زیرنویس روی ویدیو چطور نمایش داده می‌شود؛ تایمینگ، هماهنگی و ظاهر زیرنویس را قبل از خروجی نهایی به‌راحتی بررسی و تأیید کنید.
- **🎨 شخصی‌سازی کامل ظاهر زیرنویس:** بخش جدیدی اضافه شده که به شما اجازه می‌دهد فونت، رنگ متن، اندازه نوشته، رنگ/شفافیت پس‌زمینه و سایه‌ی زیرنویس را دقیقاً مطابق سلیقه‌ خودتان تنظیم کنید.
- **📖 بخش راهنمای کاربر:** یک بخش راهنمای داخلی به برنامه اضافه شده تا استفاده از تمام قابلیت‌ها، به‌خصوص برای کاربران تازه‌کار، ساده و بدون سردرگمی باشد.
- **✏️ ویرایش و بازتولید متن:** اگر جایی از ترجمه یا زیرنویس تولیدشده دقیق نبود یا دوست داشتید تغییرش بدهید، می‌توانید مستقیماً متن را ویرایش کنید و دوباره برای همان بخش تولید (Regenerate) بگیرید؛ بدون نیاز به شروع دوباره کل فرآیند.

## ✨ چرا این برنامه یک سر و گردن از بقیه بالاتر است؟

- **🌍 پشتیبانی از بیش از ۵۰ زبان دنیا:** فرقی نمی‌کند زیرنویس شما انگلیسی، کره‌ای، فرانسوی، اسپانیایی یا هر زبان دیگری باشد؛ برنامه به راحتی آن را به فارسی یا بیش از ۵۰ زبان زنده دیگر ترجمه می‌کند.
- **🎬 ساخت زیرنویس از روی ویدیوی بدون زیرنویس:** حتی اگر اصلاً فایل زیرنویس ندارید، کافیست ویدیو را بدهید تا برنامه خودش زیرنویس بسازد و سپس آن را ترجمه کنید.
- **▶️ پلیر پیش‌نمایش زیرنویس روی ویدیو:** پیش از خروجی گرفتن، مطمئن شوید زیرنویس دقیقاً همان‌طور که می‌خواهید روی ویدیو می‌نشیند.
- **🎨 شخصی‌سازی فونت، رنگ، اندازه و پس‌زمینه:** زیرنویس را کاملاً مطابق سلیقه خودتان استایل بدهید.
- **🔑 چند کلید API با سوییچ خودکار:** اگر یک کلید لیمیت بخورد یا خطا بدهد، برنامه خودکار به کلید بعدی می‌رود و کارتان متوقف نمی‌شود.
- **🎭 انتخاب لحن ترجمه (قابلیت اختصاصی):** قبل از شروع می‌توانید لحن ترجمه را دقیقاً متناسب با ویدیوی خودتان انتخاب کنید:
  * 🍿 **سینمایی و درام:** برای فیلم‌ها و سریال‌های جدی.
  * 😂 **کمدی و عامیانه:** برای سیتکام‌ها و فیلم‌های طنز (ترجمه اصطلاحات و شوخی‌ها).
  * 🎓 **آموزشی و تخصصی:** برای کورس‌ها، یوتیوب و ویدیوهای علمی.
  * 👔 **رسمی و کتابی:** برای مستندها و ویدیوهای شرکتی.
- **📖 راهنمای کاربر داخل برنامه:** دیگر نیازی نیست دنبال آموزش بگردید؛ همه‌چیز در خود برنامه توضیح داده شده.
- **✏️ اصلاح و بازتولید متن:** هر بخش از متن که به دلتان ننشست را ویرایش کنید و همان قسمت را دوباره تولید کنید؛ خیلی کاربردی برای رسیدن به بهترین نتیجه.
- **🔑 بدون نیاز به تنظیمات سخت کدنویسی:** لازم نیست بروید فایل‌های سیستم را دستکاری کنید! برنامه را که باز کنید، خیلی راحت یک دکمه وجود دارد؛ کلید API رایگان جمنای خود را درون کادر وارد می‌کنید و تمام!
- **💰 ۱۰۰٪ رایگان و بدون تبلیغات:** نیازی به خرید اشتراک یا دیدن بنرهای اعصاب‌خردکن نیست. مستقیم و بی‌واسطه با API خودتان کار می‌کند.

## ⚠️ نکات بسیار مهم (قبل از شروع)

💡 **کیفیت بالا زمان می‌برد!** به دلیل اینکه هوش مصنوعی جمنای تک‌تک جملات را با دقت بالا پردازش می‌کند و لحن انتخابی شما را روی متن اعمال می‌کند، فرآیند ترجمه **ممکن است کمی طول بکشد**. این زمان بسته به **حجم زیرنویس، سرعت اینترنت و کشش سیستم شما** متغیر است. پس اگر دیدید پردازش طولانی شد، اصلاً نگران نباشید و صبور باشید؛ برنامه دارد کارش را دقیق انجام می‌دهد! ☕️✨

🛑 **راهنمای کاربران داخل ایران (رفع تحریم):** از آنجایی که شرکت گوگل و هوش مصنوعی جمنای آی‌پی‌های ایران را مسدود کرده‌اند، برای استفاده از برنامه **حتماً باید از یک وی‌پی‌ان (VPN) مناسب استفاده کنید**. توجه داشته باشید که فیلترشکن شما باید روی حالت **تان مود (TUN Mode)** فعال باشد (برای مثال قابلیت **TUN Mode در نرم‌افزار V2ray** کاملاً کفایت می‌کند و پاسخگو است).

🎬 **نکته مهم درباره ساخت زیرنویس برای ویدیوهای طولانی:** تولید زیرنویس از روی ویدیو، به‌خصوص برای ویدیوهای طولانی، توکن زیادی از حساب Gemini شما مصرف می‌کند. اگر قصد دارید برای یک ویدیوی طولانی زیرنویس بسازید، حتماً یکی از این دو راه را در پیش بگیرید: یا **چند کلید API** به‌صورت هم‌زمان وارد کنید تا برنامه بین آن‌ها سوییچ کند، یا از یک **کلید API پولی (Paid) جمنای** استفاده کنید تا با محدودیت یا قطع‌شدن روند مواجه نشوید.

💡 **پیشنهاد برای سرعت و دقت بیشتر:** اگر ویدیوی شما از قبل یک زیرنویس خوب و دقیق به یک زبان دیگر دارد (مثلاً انگلیسی)، به‌جای اینکه از برنامه بخواهید از روی صدای ویدیو زیرنویس تازه بسازد، همان فایل زیرنویس موجود را مستقیماً به برنامه بدهید تا به زبان دلخواه شما ترجمه کند. این کار هم توکن کمتری مصرف می‌کند و هم نتیجه دقیق‌تری می‌دهد.

# Subtitle-Translator-Converter 🎬📝 (English Version)

Tired of lifeless, literal, and robotic machine translations like Google Translate? Or subtitle translation websites filled with annoying ads that end up giving you a broken or corrupted file? 🙄

This project is here to change the game! **Subtitle-Translator-Converter** allows you to translate your favorite movies, series, and educational videos into **over 50 different languages** completely **for FREE**. It delivers highly accurate and natural translations powered by **Google Gemini AI**, which understands context, idioms, and nuances just like a human translator! 😎

---

## 🆕 What's New

- **🔑 Multiple API Keys with Automatic Failover:** No more worries about hitting rate limits or a dead key! Add several Gemini API keys at once, and if one gets rate-limited or errors out, the app automatically switches to the next key so your translation never stops.
- **🎬 Automatic Subtitle Generation from Video (Speech-to-Subtitle):** One of the biggest additions in this release! Simply upload a video that has no subtitles at all (in any language), and the app automatically detects the speech and generates a subtitle file for it. From there you can translate that freshly generated subtitle into any language or edit it however you like.
- **▶️ Built-in Preview Player:** A video player has been added so you can instantly preview how the subtitles look on top of your video — check timing, sync, and appearance before exporting the final file.
- **🎨 Full Subtitle Style Customization:** A new section lets you customize the subtitle's font, text color, size, background color/opacity, and shadow exactly the way you like.
- **📖 Built-in Help/Guide Section:** An in-app guide has been added to make using every feature easier, especially for first-time users.
- **✏️ Text Editing & Regeneration:** If part of a translation or generated subtitle isn't quite right, you can edit the text directly and regenerate just that part — no need to restart the whole process.

---

## ✨ Why Choose This Tool?

- **🌍 50+ Languages Supported:** Whether your subtitle is in English, Korean, French, Spanish, or any other language, you can easily translate it into Persian or over 50 living languages worldwide.
- **🎬 Generate Subtitles from Videos with No Subtitles:** Even without a subtitle file, just upload the video and let the app create one for you, ready to translate.
- **▶️ Live Preview Player:** Verify exactly how the subtitles sit on your video before exporting.
- **🎨 Font, Color, Size & Background Customization:** Style your subtitles exactly the way you want.
- **🔑 Multiple API Keys with Auto-Switching:** If one key hits its limit or fails, the app automatically moves to the next one so nothing stops.
- **🎭 Context-Aware Tone Selection (Exclusive Feature):** Choose the perfect tone that matches your video before starting the translation:
  * 🍿 **Cinematic & Drama:** For serious movies and TV shows.
  * 😂 **Comedy & Slang:** For sitcoms and comedies (expertly translates jokes and idioms).
  * 🎓 **Educational & Technical:** For online courses, YouTube tutorials, and scientific videos.
  * 👔 **Formal & Literary:** For documentaries and corporate presentations.
- **📖 In-App User Guide:** No need to look elsewhere for instructions; everything is explained right inside the app.
- **✏️ Edit & Regenerate Text:** Edit any line you're not happy with and regenerate just that part — very handy for getting the best possible result.
- **🔑 Zero Coding Configuration:** No need to modify environment files or system settings! Simply open the app, click the dedicated button, paste your free Gemini API key(s) inside the input box, and you are ready to go!
- **💰 100% Free & Ad-Free:** No subscriptions, no limits, and no annoying pop-ups. It connects directly and privately to your own API key.
- **⏱️ Perfect Timestamp Preservation:** Your subtitle file structure remains untouched. Time codes and sequence numbers are preserved down to the millisecond—no audio-sync drifting!

---

## ⚠️ Important Notes (Before You Start)

💡 **High Quality Takes Time!** Because Gemini AI processes every sentence carefully to apply your selected tone, the translation **might take some time**. This duration depends on the **subtitle file size, your internet speed, and system capabilities**. If it seems to take a while, don't worry! The app is carefully doing its magic. Pour yourself a cup of coffee and enjoy the result! ☕️✨

🛑 **For Users Inside Iran (Bypassing Restrictions):** Since Google Gemini restricts Iranian IP addresses, **you must use a suitable VPN** to run the app. Please ensure your VPN is set to **TUN Mode** (for instance, enabling **TUN Mode in V2ray** works perfectly).

🎬 **Important Note for Long Videos:** Generating subtitles from a video — especially a long one — consumes a large number of tokens from your Gemini account. If you're generating subtitles for a long video, make sure to either use **multiple API keys** at once so the app can switch between them, or use a **paid Gemini API key** so you don't run into limits or interruptions mid-process.

💡 **Tip for Speed & Accuracy:** If your video already has a good, accurate subtitle in another language (e.g., English), it's better to feed that existing subtitle file into the app for translation rather than having the app generate a brand-new subtitle from the video's audio. This uses fewer tokens and gives more accurate results.

## 📦 Step-by-Step Installation & Quick Start

Follow these simple steps to run the application locally on your computer:

### Prerequisites

Make sure you have **Node.js** installed on your system.

### 1. Download and Extract the Project

Download the repository from GitHub and extract the Zip file anywhere on your computer.

### 2. Open Command Prompt (CMD) in the Project Folder

Navigate inside the main project directory (where the files are located). Click on the window's top address bar (where the folder path is written), type `cmd`, and press **Enter**. This opens the command prompt directly in that folder.

### 3. Install Required Packages

(Type the following command in CMD and press Enter to install dependencies; this might take a moment):

```
npm install
```

### 4. Run the App!

Launch the local server using this command:

```
npm run dev
```

Once executed, open your web browser and go to:

```
http://localhost:3000
```

**Note:** The terminal window (CMD) must remain open while using the app. Now, enter your API key(s), choose your tone, upload your subtitle or video, customize the subtitle style, preview it in the built-in player, and enjoy! 🚀

## 🆕 الجديد في هذا الإصدار

- **🔑 دعم عدة مفاتيح API مع تبديل تلقائي:** لا داعي للقلق بعد الآن من نفاد الحد المسموح أو تعطل أحد المفاتيح! يمكنك إضافة عدة مفاتيح Gemini في آن واحد، وإذا واجه أحدها حد الاستخدام أو خطأً، ينتقل التطبيق تلقائياً إلى المفتاح التالي دون أي توقف في عملية الترجمة.
- **🎬 توليد الترجمة تلقائياً من الفيديو (تحويل الكلام إلى نص):** واحدة من أبرز الإضافات في هذا الإصدار! فقط ارفع فيديو لا يحتوي على ترجمة أصلاً (بأي لغة)، وسيقوم التطبيق تلقائياً بتفريغ الكلام وإنشاء ملف ترجمة له. من هناك يمكنك ترجمة هذا الملف الجديد إلى أي لغة أو تعديله كما تشاء.
- **▶️ مشغل معاينة مدمج:** تمت إضافة مشغل فيديو داخلي لمعاينة كيفية ظهور الترجمة على الفيديو مباشرة، والتحقق من التوقيت والتناسق قبل التصدير النهائي.
- **🎨 تخصيص كامل لمظهر الترجمة:** قسم جديد يتيح لك التحكم في الخط ولونه وحجمه ولون/شفافية الخلفية وظل النص بما يناسب ذوقك تماماً.
- **📖 قسم مساعدة للمستخدم:** تمت إضافة دليل استخدام داخل التطبيق لتسهيل استخدام جميع الميزات، خصوصاً للمستخدمين الجدد.
- **✏️ تعديل النص وإعادة توليده:** إذا لم يكن جزء من الترجمة أو الترجمة المولّدة دقيقاً كما تريد، يمكنك تعديل النص مباشرة وإعادة توليد هذا الجزء فقط، دون الحاجة لإعادة العملية بأكملها.

## ✨ لماذا يُعد هذا التطبيق الأفضل؟

- **🌍 دعم أكثر من 50 لغة:** سواء كانت ترجمتك الأصلية باللغة الإنجليزية، الكورية، الفرنسية، الإسبانية، أو أي لغة أخرى، يمكنك ترجمتها بسهولة إلى العربية أو أكثر من 50 لغة حية أخرى حول العالم.
- **🎬 توليد ترجمة من فيديو بدون ترجمة:** حتى دون امتلاك ملف ترجمة، فقط ارفع الفيديو ودع التطبيق ينشئ واحداً جاهزاً للترجمة.
- **▶️ معاينة مباشرة عبر المشغل:** تحقق بدقة من شكل الترجمة على الفيديو قبل التصدير.
- **🎨 تخصيص الخط واللون والحجم والخلفية:** صمم شكل الترجمة تماماً كما تريد.
- **🔑 عدة مفاتيح API مع تبديل تلقائي:** إذا تعطل أحد المفاتيح أو وصل لحده، ينتقل التطبيق تلقائياً للمفتاح التالي.
- **🎭 اختيار نبرة وسياق الترجمة (ميزة حصرية):** يمكنك اختيار النبرة المثالية التي تناسب نوع الفيديو الخاص بك قبل البدء في الترجمة:
  * 🍿 **سينمائي ودرامي (Cinematic):** للأفلام والمسلسلات الجادة.
  * 😂 **كوميدي وعامي (Comedy):** للمسلسلات الكوميدية (ترجمة احترافية للنكات والمصطلحات الدارجة).
  * 🎓 **تعليمي وتقني (Educational):** للكورسات التعليمية، شروحات يوتيوب، والفيديوهات العلمية.
  * 👔 **رسمي وأكاديمي (Formal):** للأفلام الوثائقية وعروض الشركات.
- **📖 دليل استخدام داخل التطبيق:** لا حاجة للبحث عن شرح خارجي؛ كل شيء موضح داخل التطبيق نفسه.
- **✏️ تعديل النص وإعادة التوليد:** عدّل أي جزء من النص لا يعجبك وأعد توليده فقط؛ مفيد جداً للوصول إلى أفضل نتيجة ممكنة.
- **🔑 إعداد سهل وبدون أكواد:** لا حاجة لتعديل ملفات النظام أو الإعدادات المعقدة! بمجرد فتح التطبيق، ستجد زراً مخصصاً؛ قم بلصق مفتاح (أو مفاتيح) الـ API المجانية من Gemini داخل المربع وابدأ فوراً!
- **💰 مجاني 100% وبدون إعلانات:** لا توجد اشتراكات، ولا حدود، ولا نوافذ منبثقة مزعجة. يتصل التطبيق مباشرة وبخصوصية تامة بمفتاح الـ API الخاص بك.
- **⏱️ الحفاظ التام على التوقيت (Timing):** يظل هيكل ملف الترجمة كما هو دون أي تغيير. يتم الحفاظ على التوقيتات وأرقام السطور بدقة متناهية تصل إلى الأجزاء من الثانية، لضمان عدم حدوث أي تأخير أو تقديم في الصوت!

## ⚠️ تنبيهات هامة جداً (قبل البدء)

💡 **الجودة العالية تستغرق وقتاً!** نظراً لأن الذكاء الاصطناعي Gemini يقوم بمعالجة كل جملة بعناية لتطبيق النبرة التي اخترتها، فإن عملية الترجمة **قد تستغرق بعض الوقت**. تعتمد هذه المدة على **حجم ملف الترجمة، سرعة الإنترنت لديك، وكفاءة جهازك**. إذا لاحظت أن المعالجة تستغرق وقتاً، فلا تقلق! التطبيق يعمل بدقة؛ استمتع بكوب من القهوة وانتظر النتيجة المذهلة! ☕️✨

🛑 **للمستخدمين داخل إيران (تخطي الحجب):** نظراً لأن شركة Google تحظر عناوين الـ IP الإيرانية من استخدام Gemini، **يجب عليك استخدام VPN مناسب** لتشغيل التطبيق. يرجى التأكد من تفعيل وضع **TUN Mode** في الفيلترشكن الخاص بك (على سبيل المثال، تفعيل **TUN Mode في برنامج V2ray** يفي بالغرض تماماً).

🎬 **ملاحظة هامة بخصوص الفيديوهات الطويلة:** توليد الترجمة من الفيديو، خصوصاً الفيديوهات الطويلة، يستهلك عدداً كبيراً من التوكنات من حساب Gemini الخاص بك. إذا كنت ستنشئ ترجمة لفيديو طويل، احرص على استخدام **عدة مفاتيح API** في آن واحد ليتمكن التطبيق من التبديل بينها، أو استخدام **مفتاح API مدفوع** من Gemini لتجنب الوصول إلى الحد المسموح أو انقطاع العملية.

💡 **نصيحة لسرعة ودقة أفضل:** إذا كان الفيديو الخاص بك يحتوي بالفعل على ترجمة جيدة ودقيقة بلغة أخرى (مثل الإنجليزية)، فمن الأفضل رفع ملف الترجمة الموجود مباشرة إلى التطبيق ليقوم بترجمته إلى اللغة التي تريدها، بدلاً من جعل التطبيق ينشئ ترجمة جديدة من صوت الفيديو. هذا يوفر توكنات أقل ويعطي نتائج أدق.

## 📦 دليل التثبيت والتشغيل خطوة بخطوة

اتبع هذه الخطوات البسيطة لتشغيل التطبيق محلياً على جهاز الكمبيوتر الخاص بك:

### المتطلبات الأساسية

تأكد من تثبيت برنامج **Node.js** على نظامك.

### 1. تحميل وفك ضغط المشروع

قم بتحميل المشروع من GitHub وفك ضغط ملف الـ Zip في أي مكان على جهازك.

### 2. فتح موجه الأوامر (CMD) في مجلد المشروع

ادخل إلى المجلد الرئيسي للمشروع (حيث توجد الملفات). اضغط على شريط العنوان العلوي للنافذة (حيث يظهر مسار المجلد)، واكتب `cmd` ثم اضغط **Enter**. سيفتح لك موجه الأوامر مباشرة داخل المجلد.

### 3. تثبيت الحزم المطلوبة

(اكتب الأمر التالي في CMD واضغط Enter لتثبيت الملفات المساعدة؛ قد تستغرق هذه العملية بعض الوقت):

```
npm install
```

### 4. تشغيل التطبيق والاستخدام!

قم بتشغيل السيرفر المحلي باستخدام هذا الأمر:

```
npm run dev
```

بمجرد التشغيل، افتح متصفح الويب واذهب إلى الرابط التالي:

```
http://localhost:3000
```

**ملاحظة:** يجب أن تظل نافذة الـ CMD مفتوحة أثناء استخدام التطبيق. الآن، أدخل مفتاح (أو مفاتيح) الـ API الخاصة بك، اختر النبرة المفضلة، ارفع الترجمة أو الفيديو، خصّص شكل الترجمة، وشاهد النتيجة في المشغل واستمتع! 🚀
