# Subtitle-Translator-Converter 🎬📝 (نسخه فارسی)

خسته شدی از ترجمه‌های بی‌روح، ماشینی و کلمه به کلمه‌ی گوگل ترنسلیت؟ یا سایت‌های ترجمه زیرنویسی که هم کلی تبلیغ دارند و هم آخرش یک فایل خراب و بی‌معنی تحویلت می‌دهند؟ 🙄

این پروژه اینجاست تا کار را تمام کند! **Subtitle-Translator-Converter** به شما اجازه می‌دهد کاملاً **رایگان**، فیلم‌ها، سریال‌ها و ویدیوهای آموزشی محبوبتان را به **بیش از ۵۰ زبان مختلف دنیا** و با دقیق‌ترین و طبیعی‌ترین لحن ممکن ترجمه کنید. چطوری؟ با قدرت هوش مصنوعی **Gemini** که اصطلاحات و ریزه‌کاری‌های زبان را مثل یک مترجم انسان می‌فهمد! 😎

## ✨ چرا این برنامه یک سر و گردن از بقیه بالاتر است؟

- **🌍 پشتیبانی از بیش از ۵۰ زبان دنیا:** فرقی نمی‌کند زیرنویس شما انگلیسی، کره‌ای، فرانسوی، اسپانیایی یا هر زبان دیگری باشد؛ برنامه به راحتی آن را به فارسی یا بیش از ۵۰ زبان زنده دیگر ترجمه می‌کند.
- **🎭 انتخاب لحن ترجمه (قابلیت اختصاصی):** قبل از شروع می‌توانید لحن ترجمه را دقیقاً متناسب با ویدیوی خودتان انتخاب کنید:
  * 🍿 **سینمایی و درام:** برای فیلم‌ها و سریال‌های جدی.
  * 😂 **کمدی و عامیانه:** برای سیتکام‌ها و فیلم‌های طنز (ترجمه اصطلاحات و شوخی‌ها).
  * 🎓 **آموزشی و تخصصی:** برای کورس‌ها، یوتیوب و ویدیوهای علمی.
  * 👔 **رسمی و کتابی:** برای مستندها و ویدیوهای شرکتی.
- **🔑 بدون نیاز به تنظیمات سخت کدنویسی:** لازم نیست بروید فایل‌های سیستم را دستکاری کنید! برنامه را که باز کنید، خیلی راحت یک دکمه وجود دارد؛ کلید API رایگان جمنای خود را درون کادر وارد می‌کنید و تمام!
- **💰 ۱۰۰٪ رایگان و بدون تبلیغات:** نیازی به خرید اشتراک یا دیدن بنرهای اعصاب‌خردکن نیست. مستقیم و بی‌واسطه با API خودتان کار می‌کند.
- **⏱️ حفظ کامل زمان‌بندی (Timing):** ساختار فایل زیرنویس شما دقیقاً حفظ می‌شود و زمان‌بندی‌ها حتی یک میلی‌ثانیه هم جابه‌جا نمی‌شوند.

It delivers highly accurate and natural translations powered by **Google Gemini AI**, which understands context, idioms, and nuances just like a human translator! 😎

## ✨ Why Choose This Tool?

- **🌍 50+ Languages Supported:** Whether your subtitle is in English, Korean, French, Spanish, or any other language, you can easily translate it into Persian or over 50 living languages worldwide.
- **🎭 Context-Aware Tone Selection (Exclusive Feature):** Choose the perfect tone that matches your video before starting the translation:
  * 🍿 **Cinematic & Drama:** For serious movies and TV shows.
  * 😂 **Comedy & Slang:** For sitcoms and comedies (expertly translates jokes and idioms).

  * 👔 **Formal & Literary:** For documentaries and corporate presentations.

- **⏱️ Perfect Timestamp Preservation:** Your subtitle file structure remains untouched. Time codes and sequence numbers are preserved down to the millisecond—no audio-sync drifting!

## 📦 Step-by-Step Installation & Quick Start (Local Setup)

If you'd rather run the app on your own machine, follow these simple steps:

### Prerequisites

Make sure you have **Node.js** installed on your system.

### 1. Download and Extract the Project

Download the repository from GitHub and extract the Zip file anywhere on your computer.

### 2. Open Command Prompt (CMD) in the Project Folder

Navigate inside the main project directory (where the files are located). Click on the window's top address bar (where the folder path is written), type `cmd`, and press **Enter**. This opens the command prompt directly in that folder.

### 3. Install Required Packages

(Type the following command in CMD and press Enter to install dependencies; this might take a moment):

```
npm install
```

### 4. Run the App!

Launch the local server using this command:

```
npm run dev
```

Once executed, open your web browser and go to:

```
http://localhost:3000
```

**Note:** The terminal window (CMD) must remain open while using the app. Now, enter your API key, choose your tone, upload your subtitle, and enjoy! 🚀
